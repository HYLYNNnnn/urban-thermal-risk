# 城市热风险项目使用说明

## 现在的项目重点

百度地图 API 获取街景是上游数据来源说明。本仓库主要展示：**已有街景/鱼眼图 → PyTorch 语义分割 → 环境指标 → 点位表合并 → XGBoost/SHAP**。不需要填写百度 API key，也不会运行原来的网页爬虫。

上传 GitHub 时，在 GitHub Desktop 中选择整个 `urban-thermal-risk` 文件夹，建议仓库名同名。前面五个应用项目保持独立。

## 先看成果

可以直接打开根目录 README，或查看 `docs/examples/`。其中有真实街景/鱼眼叠加图、逐图和逐点指标、历史数据核对及本轮模型评估，不需要先安装程序。大压缩包仍完整保留在原位置；源码副本只带四方向街景各一张和同一点鱼眼图，共五张示例。

## 本地运行

安装 Python 3.12 后，在项目根目录打开终端：

```sh
python -m venv .venv
```

Windows PowerShell 激活：

```powershell
.\.venv\Scripts\Activate.ps1
```

Mac 激活：

```sh
source .venv/bin/activate
```

再安装依赖：

```sh
python -m pip install -r requirements.txt
```

Mac 如果 XGBoost 提示缺少 `libomp.dylib`，需要安装 OpenMP 运行库；使用 Homebrew 的环境可执行 `brew install libomp`。本轮核查在独立临时环境中使用 PyTorch 随带的 OpenMP 库完成，没有更改系统开发目录。

### 分割示例

```sh
python -m segmentation.infer --input data/samples/street --output outputs/street --view street
python -m segmentation.infer --input data/samples/fisheye --output outputs/fisheye --view fisheye
```

首次运行会下载约 55 MB 的官方 SegFormer-B1 模型；以后可以复用缓存。默认 CPU。输出目录必须新建或为空，避免混入旧结果。

结果中 `raw_masks` 是可重新统计的类别编号图，`color_masks` 是彩色分割图，`overlays` 是叠加图。`metrics.csv` 记录每张图，`point_metrics.csv` 记录点位均值，`run.json` 记录模型版本、处理尺寸和失败情况。

### 合并点位特征

```sh
python -m segmentation.merge --street outputs/street/point_metrics.csv --fisheye outputs/fisheye/point_metrics.csv --context data/processed/historical_features.csv --output outputs/sample-features.csv --allow-partial
```

示例只有点位 1，因此输出一条合并记录，并明确报告另外 237 点没有本次新分割结果。不会用旧结果伪装补齐新结果。正式整批合并时应去掉 `--allow-partial`，缺失点位会报错。

H/W、房价、人口、POI 和路网密度来自传入的既有数据表，不是由分割模型凭空生成。新图片字段替换到点位表后，会另存来源说明。

### 历史核对与建模

```sh
python -m segmentation.history --data-dir data/historical --features data/processed/historical_features.csv --output outputs/reconciliation.json
python -m analysis.train --input data/processed/historical_features.csv --output outputs/analysis --max-estimators 100 --early-stopping-rounds 15
```

单点示例不能用于训练评价，所以建模使用原始 238 点完整特征表。结果包括 THIR、风险等级、训练/验证/测试划分、模型文件、评价指标和 SHAP 图。

## 模型名称和指标口径

原来的 `Segment_deeplab_city.py` 实际调用 SegFormer-B5，`fisheyes.py` 调用 SegFormer-B1。整理后的正式入口因此明确写为 **PyTorch / SegFormer / Cityscapes**；有类别映射错误的旧实验放在 `reference/`，不作为运行入口。

历史 GVI/TVF 把 vegetation 和 terrain 合计。为能对照原报告，这个口径被保留，同时单独给出 `vegetation_only_fraction`，避免把所有地面都当成植物。鱼眼指标也保留原来的圆形范围和 sin(theta) 加权计算，属于原研究的代理指标；没有相机标定信息，不应当成已校准的物理辐射测量。

本轮支持直接分割已有鱼眼图；图片拼接、街景到鱼眼图的生成程序仍未找回。ArcGIS Pro 工程和完整原始图层也仍缺。现存 H/W 是经验像素比例估计，不应写成已经找回训练好的高宽比模型。
